# Fixloop

Maintenance coordination for small property-management firms. Fixloop sits beside the firm's PMS. Every open repair has an owner, a clock and a one-tap link. Vendors, tenants and owners act through no-login links; only property managers have accounts. `Fixloop` is a working codename.

```bash
pnpm dev     # everything up (Docker, migrations, API, worker, web) + demo data on first run
pnpm check   # install, auto-fix, lint, typecheck, tests, build budget, security, code health
```

Then open http://localhost:5173 and sign in as `admin@greenvalley.test` / `Fixloop-demo-2026!`. Fixloop staff use the superadmin console at `/ops` (accounts are created with `pnpm superadmin add`; see DEVELOPMENT.md).
